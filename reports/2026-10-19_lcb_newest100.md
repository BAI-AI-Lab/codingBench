# LiveCodeBench 最新 100 题：DeepSeek-V4.1-Flash 对比 Qwen2.5-3B-Instruct

2026-10-19，在实验室 GPU 服务器上用本仓库的 `cb` 跑。

## 设置

- **题目**：LiveCodeBench release_v6 里发布日期最新的 100 题（`samples/lcb_newest100.txt`），2025-02-15 到 2025-04-06。简单 23、中等 30、困难 47；AtCoder 66、LeetCode 34。
- **打分**：官方提示词和官方判题程序（隐藏测试用例全部通过才算对），每题 1 次，temperature 0.2，pass@1。
- **DeepSeek-V4.1-Flash**：DeepSeek 官方 API，模型名 `deepseek-flash`，推理模型。
  - 先用 65536 token 上限跑了一轮。
  - 有 4 道困难题思考用完了上限、没写出答案，把这 4 题用 262144 上限重跑了一次。
  - 下面用的是 262144 的成绩，两种上限的差别见文末。
- **Qwen2.5-3B-Instruct**：服务器本地部署（vLLM），不设 token 上限，回答可以写到上下文用满（32768）为止。实际最长的回答约 3400 字符，没有一题被截断。

## 没通过的原因

| 原因 | DeepSeek-V4.1-Flash | Qwen2.5-3B |
|---|---:|---:|
| 答案错误 | 5 | 48 |
| 运行错误或编译失败 | 4 | 14 |
| 超时 | 0 | 6 |
| 没有给出代码 | 0 | 21 |
| 其他错误 | 0 | 1 |
| 合计 | 9 | 90 |

- **DeepSeek**：4 个运行错误里，3 个是读输入的格式写错了（abc395_e、abc396_d、abc400_d，都是 `ValueError: ... values to unpack`，比如第一行有 3 个数却按 2 个读）；1 个是程序里数组越界（abc394_g，`IndexError`）。都是代码本身的错，不是运行环境的问题。
- **Qwen**：「没有给出代码」的 21 题，全部是它写完代码后又附了一个空的模板代码块。官方规则取最后一个代码块，所以记为没有代码。

## token 上限对 DeepSeek 的影响

| 上限 | 通过 |
|---|---:|
| 65536 | 88/100 |
| 262144 | 91/100 |

在 65536 上限下有 4 道困难题没写出答案。上限放到 262144 后，其中 3 题做对（arc193_d、arc195_d、arc196_c），1 题答错（abc398_g）。所以推理模型一定要给足 token，否则测出来的是上限，不是能力。

## 解读时要注意

- **题目可能已经被模型见过**：这 100 题发布于 2025 年 2–4 月，很可能早于 DeepSeek-V4.1-Flash 的训练数据截止时间，不能当作完全没见过的新题。release_v6 是 LiveCodeBench 目前最新的版本，没有更新的题。
- **单次结果有误差**：每题只跑 1 次，100 题的 pass@1 大约有 ±3 个百分点的波动。
- **两个模型不在一个量级**：Qwen2.5-3B 是 2024 年的 3B 非推理小模型，这组对比主要说明测试的区分度够大，不代表同级别模型之间的差距。

## 复现

```bash
# DeepSeek（OPENAI_API_KEY 换成自己的）
export MODEL=deepseek-flash OPENAI_BASE_URL=https://api.deepseek.com/v1 OPENAI_API_KEY=sk-...
MAX_TOKENS=65536 WORKERS=16 LCB_IDS=samples/lcb_newest100.txt cb livecodebench
MAX_TOKENS=262144 LCB_TIMEOUT=3600 WORKERS=16 LCB_IDS=samples/lcb_newest100.txt cb livecodebench   # 只重跑空答案的题
cb report deepseek-flash/livecodebench-lcb_newest100-full

# 本地 Qwen（vLLM，--max-model-len 32768）
export MODEL=qwen2.5-3b-instruct OPENAI_BASE_URL=http://127.0.0.1:12340/v1 OPENAI_API_KEY=local
MAX_TOKENS=none WORKERS=16 LCB_TIMEOUT=3600 LCB_IDS=samples/lcb_newest100.txt cb livecodebench
```

每道题的结果见服务器上的 `runs/<模型>/livecodebench-lcb_newest100-full/report.md`。
